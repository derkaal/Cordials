# Professional Recipe Database

This area holds verified professional formulations, each linked to one or more source records. Create records from `templates/professional_recipe_record.md` and index them in `recipe_index.csv`.

Do not reconstruct missing quantities, methods, yields, or attributions. Use `UNKNOWN`. An adaptation belongs in its own record and must show every departure from the source.

`geographic_coverage.csv` records the validated base region and country of the responsible professional, venue or commercial operator. It must not be inferred from flavour associations, page language, a domain suffix or a delivery market. Product research should actively search both Asian and European professional/commercial sources where relevant and record gaps without inventing a recipe.

`quarantine/` contains stable formulation leads that are not approved as exact sourced recipes. A recipe ID provides traceability; it does not imply provenance validation or permission to execute the formulation as Batch 001.

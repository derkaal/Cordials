# ID Conventions

IDs are permanent once assigned. Never reuse an ID, even if a record is withdrawn or archived.

| Record | Pattern | Example |
|---|---|---|
| Product brief | `PB-NNN` | `PB-001` |
| Product research task | `RT-{PRODUCT_ID}-NNN` | `RT-PB-001-001` |
| Research import package | `IMP-YYYY-NNN` | `IMP-2026-001` |
| Source | `SRC-YYYY-NNN` | `SRC-2026-001` |
| Professional recipe | `PR-NNNN` | `PR-0001` |
| Candidate assessment | `CA-{CORDIAL}-VNN` | `CA-YUZU-V01` |
| Experimental batch | `B-YYYYMMDD-{CORDIAL}-VNN-NN` | `B-20260829-YUZU-V01-01` |
| Application test | `AT-YYYYMMDD-NNN` | `AT-20260829-001` |
| Shelf-life observation series | `SL-{BATCH_ID}` | `SL-B-20260829-YUZU-V01-01` |
| Cost/yield calculation | `CY-{BATCH_ID}-VNN` | `CY-B-20260829-YUZU-V01-01-V01` |
| Decision | `DEC-YYYY-NNN` | `DEC-2026-001` |
| Glass-cling trial | `GC-YYYYMMDD-{PRODUCT_ID}-NN` | `GC-20260830-PB001-01` |

Use short product codes consistently: `YUZU`, `STRVAN`, `PECTHY`, `LYCH`, `PAND`, `MANG`, and `PUMPMAT`.

# Laboratory Notebook

The laboratory notebook is an append-only record of every attempted batch, including failures. Create a batch file from `templates/experimental_batch.md` before starting work, then register it in `batch_register.csv`.

Never delete failed batches or rewrite observations to match later conclusions. Corrections should be dated addenda that preserve the original entry.

## Bench-measurability standard

- Write operational ingredient quantities in units the named equipment can measure directly.
- Prefer grams for working quantities of 10 g or more.
- For an active house-batch ingredient quantity below 10 g, use a standard measuring teaspoon and practical level-spoon fractions. Keep the source gram amount and the conversion basis in the lineage record; do not imply that volume is an exact mass equivalent.
- Prefer whole grams at 10 g or more. Use decimal grams only in the preserved source calculation or when the operator explicitly chooses to record a check weight.
- Do not put awkward calculator outputs such as `31.25 ml` into a bench recipe merely to preserve a scaling percentage.
- If exact scaling creates impractical micro-quantities, enlarge the batch or round deliberately. Record the difference from the source and retain the correct provenance classification.
- Keep source-stated quantities in the professional recipe or adaptation table; the working ingredient table must remain operator-friendly.
- A teaspoon means a standard 5 ml measuring spoon, levelled without packing unless the batch explicitly says otherwise. Cutlery teaspoons are not valid measures.
- This rule does not rewrite exact professional source records or analytical test quantities. If a future source-only recipe states a sub-10 g ingredient, preserve that source value and document an ingredient-specific spoon conversion in the project adaptation before opening an operational batch.
